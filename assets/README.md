# Assets

This repo ships no memes, sound effects, music, or reference video. Add only
assets you own or have a license to use.

Suggested folders:

```text
assets/
├── memes/    reaction images, GIFs, short video loops
├── sfx/      whooshes, impacts, record scratches, meme sounds
└── music/    tracks cleared for the platform you publish on
```

Keep a `SOURCES.md` in each folder with the source URL, license, and attribution
if required. Do not commit assets you cannot redistribute.
